# Sugestão de post para LinkedIn

Depois de algumas iterações, finalizei uma versão apresentável do TaskFlow Field, um projeto full stack para equipes de serviço em campo.

A ideia é simples: tirar pequenas operações do improviso com WhatsApp, planilhas e papel, oferecendo um fluxo mais organizado para criar ordens de serviço, atribuir técnicos, acompanhar status, cumprir checklist e registrar evidências.

O que desenvolvi:

- Painel web em React/Vite com dashboard, filtros, cadastro de OS, exportação CSV, trial e planos.
- API em Node.js/Express com MongoDB, autenticação JWT e rotas versionadas.
- App mobile em Expo/React Native para técnicos em campo, com checklist, status, foto de comprovante e cache offline.
- Deploy com Vercel, Render e MongoDB Atlas.
- Conta demo e screenshots profissionais para apresentação.

Foi um projeto importante para praticar decisões de produto, experiência de usuário, integração frontend/backend/mobile e estrutura de deploy real.

Estou buscando oportunidades como Desenvolvedor Full Stack Júnior ou Pleno, principalmente onde eu possa continuar evoluindo em produto, frontend, backend e mobile.
